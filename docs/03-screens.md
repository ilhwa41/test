# 03. 메인 화면 구성과 화면 흐름

> 발주 타이밍 알림 시스템 기획 문서 · 2026-11-07 · 근거: 프로젝트 회의(바이브코딩 팀), 시안 이미지
>
> 이 문서는 `06-design.md`의 시안("업무 중심형")에 맞춰 정리했다. 색·글꼴·모바일 배치 규칙은 06번 문서를 따른다.

## 1. 메뉴

| 메뉴 | 열리는 화면 |
|---|---|
| 대시보드 | 첫 화면 (아래 2번) |
| 입력하기 | 사용 입력 / 입고 입력 화면 (탭으로 전환) |
| 발주 기록 | 발주 내역과 입고 여부 |
| 설정 | 알림 받을 이메일, 알림 시간 |

- 큰 화면에서는 왼쪽 사이드바에, 작은 화면에서는 하단 탭에 같은 4개를 둔다.
- 상단 바에는 오늘 날짜, 알림 벨, 사용자 이름이 있다.
  - 알림 벨: 알림 기록 화면으로 이동
  - 사용자 이름: 메뉴가 열리고 로그아웃을 할 수 있다

## 2. 첫 화면 (대시보드)

위에서 아래로 다음 순서로 보인다.

1. **인사 배너**: 현재 상태를 한 줄로 알려준다. 문구는 상태에 따라 바뀐다. (아래 "배너 문구 규칙")
2. **빠른 입력 버튼 3개**
   - **사용 입력** (파랑): 오늘 쓴 수량을 바로 입력
   - **입고 입력** (초록): 들어온 수량을 바로 입력
   - **품목 추가 +** (흰색): 새 품목 등록
3. **알림이 필요한 품목** (왼쪽 큰 영역)
   - 상태가 **발주 필요** 또는 **주의**인 품목만 보인다. 발주가 급한 순서(D-숫자가 작은 순)로 정렬한다.
   - 카드 내용: 품목 아이콘, 품목 이름, 남은 수량, D-숫자(소진 예상일), 상태 배지, 막대
   - **전체 보기**: 모든 품목을 볼 수 있는 전체 품목 목록으로 이동
4. **최근 활동 내역** (오른쪽 영역)
   - 입고·사용 기록의 최근 3건. 내용(품목, 수량)과 날짜·시간을 보여준다. 입고는 초록 체크, 사용은 파랑 연필 아이콘으로 구분한다.
   - **전체 보기**: 활동 기록 화면으로 이동

### 상태
| 상태 | 의미 | 알림이 필요한 품목에 표시 |
|---|---|---|
| 정상 | 발주점보다 충분히 많음 | 표시 안 함 |
| 주의 | 발주점에 가까워짐 | 표시 |
| 발주 필요 | 발주점 이하 | 표시 |
| 입고 대기 | 발주를 마치고 입고를 기다리는 중 (발주 알림 멈춤) | 표시 안 함. 전체 품목 목록에서 확인 |

- **긴급**: 남은 수량이 긴급 알림 기준 이하이면 배지를 "긴급"으로 바꾸고 가장 진한 빨강으로 표시한다. 입고 대기 중인 품목도 긴급이면 "알림이 필요한 품목"에 표시하고, 카드에 입고 예정일을 함께 보여준다.

### 배너 문구 규칙
시안에는 "정상" 문구만 있어서, 상태별 문구는 아래처럼 제안한다.

| 상황 | 문구 | 아이콘 색 |
|---|---|---|
| 발주 필요 품목이 1개 이상 | "발주가 필요한 품목이 N개 있어요" | 빨강 (경고) |
| 발주 필요는 없고 주의가 1개 이상 | "곧 발주할 품목이 N개 있어요" | 주황 |
| 모두 정상 | "오늘도 수고 많으세요! 현재 N개 품목이 정상적으로 관리되고 있습니다." | 초록 (체크) |

- 입고 대기 품목이 있으면 문구 아래에 "입고 대기 N개"를 작게 덧붙인다.
- 등록된 품목이 하나도 없으면 "품목을 추가해서 시작해 보세요"와 품목 추가 버튼을 강조한다.

## 3. 화면 목록

| 화면 | 하는 일 | 시안 |
|---|---|---|
| 로그인 | 로그인 | 없음 |
| 대시보드 | 상태 한눈에 보기, 빠른 입력 | 있음 |
| 입력하기 | 사용 입력 / 입고 입력을 탭으로 전환. 품목 선택, 수량, 날짜, 메모 입력 | 버튼만 있음 |
| 전체 품목 목록 | 모든 품목과 상태. 상태별로 걸러 보기 | 없음 |
| 품목 상세 | 남은 수량 변화, 사용·입고 기록, 발주점 설정, 품목 수정 | 없음 |
| 품목 추가/수정 | 품목 기본 정보와 기준값 입력 | 버튼만 있음 |
| 발주 완료 입력 | 발주 수량, 입고 예정일 입력 | 없음 |
| 발주 기록 | 발주 내역과 입고 여부, 입고 처리 | 메뉴만 있음 |
| 활동 기록 | 입고·사용 기록 전체 (재고 기록 `stockLogs`) | 일부 있음 (최근 3건) |
| 알림 기록 | 보낸 알림 목록 (`alerts`) | 벨 아이콘만 있음 |
| 설정 | 알림 받을 이메일, 알림 시간 | 메뉴만 있음 |

"시안: 없음"인 화면은 06-design.md의 색·글꼴·카드 규칙을 같게 적용해서 만든다.

## 4. 화면 흐름

```
로그인
  └─ 대시보드
       ├─ [사용 입력] ─ 입력하기 (사용 탭) ─ 저장 ─ 대시보드
       ├─ [입고 입력] ─ 입력하기 (입고 탭) ─ 저장 ─ 대시보드
       ├─ [품목 추가 +] ─ 품목 추가/수정 ─ 저장 ─ 대시보드
       ├─ 알림이 필요한 품목 [전체 보기] ─ 전체 품목 목록 ─ 품목 상세
       ├─ 품목 카드 선택 ─ 품목 상세 ─ 사용/입고 입력 (입력하기)
       │                         ├─ 발주 완료 입력
       │                         └─ 품목 수정
       ├─ 최근 활동 내역 [전체 보기] ─ 활동 기록
       ├─ 알림 벨 ─ 알림 기록 ─ 품목 상세
       └─ 사용자 이름 ─ 로그아웃

메뉴로 이동: 대시보드 / 입력하기 / 발주 기록 / 설정

[이메일 알림] ─ 링크 ─ 해당 품목 상세 ─ 발주 완료 입력
```

## 5. 화면별 동작 메모

- **입력하기**: 대시보드의 빠른 입력 버튼에서 오면 해당 탭(사용 또는 입고)이 열려 있고, 품목 카드에서 오면 그 품목이 미리 선택되어 있다. 저장하면 재고가 바뀌고 `stockLogs`에 기록이 남는다.
- **발주 완료 입력**: 저장하면 품목 상태가 "입고 대기"로 바뀌고 알림이 멈춘다. `orders`에 발주 기록이 생긴다.
- **발주 기록**: 입고가 되면 이 화면에서 "입고 처리"를 누른다. 재고가 올라가고 상태가 다시 계산된다.
- **품목 상세·품목 추가/수정**: 발주 알림 기준과 긴급 알림 기준은 대표가 직접 입력한 수량이 기본이다. 하루 사용량과 입고까지 걸리는 일수로 구한 "추천 발주점"은 입력 칸 옆에 참고로만 보여주고 자동 적용하지 않는다.
- **이메일 알림 링크**: 로그인이 안 되어 있으면 로그인 후 해당 품목 상세로 돌아온다.
